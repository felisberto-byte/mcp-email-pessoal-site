Política de Privacidade

MCP E-mail Pessoal · página inicial

1. Quem usa

O MCP E-mail Pessoal é um aplicativo de uso exclusivo do seu dono, Carlos Martins. Somente a conta Google do dono é aceita; qualquer outra conta é recusada no login.

2. Quais dados são acessados

Com a autorização do dono, o aplicativo acessa a caixa do Gmail dele pelas permissões gmail.modify (ler mensagens e anexos, criar rascunhos, aplicar marcadores, mover para a lixeira ou para o spam) e gmail.settings.basic (criar e apagar filtros), além de openid e email para confirmar a identidade de quem entra.

3. Como os dados são usados

  • Os dados do Gmail são usados somente para atender aos pedidos que o próprio dono faz, por meio do assistente Claude.
  • O aplicativo nunca envia e-mails e não exclui mensagens definitivamente.
  • Os dados não são vendidos, compartilhados com terceiros, usados para publicidade nem para treinar modelos de inteligência artificial.

4. O que fica guardado

  • A autorização de acesso ao Gmail fica guardada de forma cifrada no Google Cloud Secret Manager.
  • As sessões de login ficam no Google Cloud Firestore, apenas como códigos cifrados (hashes), e expiram sozinhas.
  • Na limpeza em massa, a prévia guarda no Firestore, por até 10 minutos, a busca e os identificadores das mensagens afetadas, até o dono confirmar.
  • Cada alteração feita na caixa é registrada no log do servidor (operação, identificadores, assunto e destinatários), sem o corpo das mensagens.
  • O conteúdo das mensagens não é armazenado pelo aplicativo.

Toda a infraestrutura fica em um projeto Google Cloud do próprio dono, na região de São Paulo.

5. Política de Dados do Usuário das APIs do Google

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar

O acesso pode ser cortado a qualquer momento em myaccount.google.com/permissions, removendo o aplicativo "MCPs Pessoais do Carlos".
